# ECD Resource Hub

A React dashboard starter for organizing Early Childhood Development resources from the RECS collection.

## Run in GitHub Codespaces

Open the repository in a Codespace. The development container installs the packages when it is created. In the terminal, run:

```bash
npm run dev
```

Codespaces will forward port 5173 and open the dashboard preview.

## Run locally

```bash
npm install
npm run dev
```

## Current scope

The dashboard includes sample resource cards for curriculum, activity books, kits, and furniture, plus search and format filtering. The sample entries are placeholders. OneDrive integration and real RECS files have not been added.

Do not commit confidential documents, credentials, or learner information to this repository.
